# Example environment maps

The default `configs/inference.json` selects these HDRIs and lighting settings:

| File | Batch lighting |
| --- | --- |
| blinds_1k.hdr | Fixed |
| cobblestone_street_night_1k.hdr | Fixed |
| dry_field_1k.hdr | One clockwise rotation |
| park_bench_1k.hdr | Fixed |

With the six included videos this produces 24 runs. Panorama previews use the
source file orientation, consistent with the supplied examples. These are media
assets with their own provenance; see [third-party notices](../../THIRD_PARTY_NOTICES.md).
